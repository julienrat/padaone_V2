# Polices embarquées

Déposer ici, au format woff2 :

- `BricolageGrotesque.woff2` (titres)
- `Lexend.woff2` (texte)

Les deux sont sous licence SIL Open Font License et se téléchargent sur Google Fonts
(fichier variable, sous-ensemble latin suffisant). Elles sont embarquées dans le binaire :
aucune police n'est chargée depuis internet pendant une séance. Joindre le fichier de licence `OFL.txt`.
