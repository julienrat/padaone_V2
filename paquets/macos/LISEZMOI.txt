PADAONE POUR MACOS
==================

Les téléphones des participants deviennent des outils de participation ;
les résultats s'affichent au vidéoprojecteur. Tout reste sur ce Mac.
Fonctionne sur les Mac Apple (M1, M2…) comme sur les Mac Intel.

LANCER
------
1. Décompressez le fichier zip (double-clic), puis ouvrez le dossier Padaone.
2. Première fois : macOS bloque les programmes non signés par Apple.
   Faites un clic droit (ou Ctrl+clic) sur « Padaone » > Ouvrir > Ouvrir.
   Si macOS refuse encore : Réglages Système > Confidentialité et sécurité >
   « Ouvrir quand même ». Ou dans le Terminal :
     xattr -d com.apple.quarantine ~/Downloads/Padaone/Padaone
3. Le Terminal s'ouvre avec le code et les liens de la séance ; la console s'ouvre
   dans le navigateur. Projetez le lien « Écran » au vidéoprojecteur.
4. Si macOS demande d'accepter les connexions entrantes : acceptez, sinon les
   téléphones ne pourront pas joindre le Mac.
5. Pour terminer : Ctrl+C dans le Terminal.

RÉSEAU
------
Les téléphones doivent être sur le même Wi-Fi que le Mac. Le point d'accès Wi-Fi
piloté par Padaone n'existe que sous Linux pour l'instant : sur Mac, utilisez le
Wi-Fi de la salle ou un routeur de voyage.

OPTIONS
-------
Dans le Terminal, depuis ce dossier :
  ./Padaone --titre "Formation jour 1" --ouvrir-console
  ./Padaone --help
